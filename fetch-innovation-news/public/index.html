เพิ่มแหล่งข้อมูลใหม่

แหล่งข่าวใหม่จะเริ่มเป็น Inactive ก่อน และควรทดสอบการดึงให้ผ่านก่อนเปิดใช้งาน

ใช้กับ endpoint แบบ `/wp-json/wp/v2/posts`

กรอก mapping แบบ dot-path เช่น `data.items`, `title.rendered`, `url`, `published_at`

เว้นว่างได้ ระบบจะใช้ title แทนถ้าไม่พบ summary

รูปแบบข้อมูลที่รองรับ

RSS

พร้อมใช้งาน

ใช้กับ feed มาตรฐาน เช่น `/feed/`, `.rss`, หรือ `.xml` ที่คืนรายการข่าวโดยตรง ระบบจะใช้ generic RSS fetcher ทันที

ตัวอย่าง: `https://example.com/feed/`

API (WordPress API)

พร้อมใช้งาน

ใช้กับ WordPress REST API เช่น `/wp-json/wp/v2/posts` ระบบจะใช้ generic WordPress API fetcher ได้ทันที

ตัวอย่าง: `https://example.com/wp-json/wp/v2/posts`

API (Generic JSON)

พร้อมใช้งาน

ใช้กับ public JSON API ที่มี endpoint เดียว และสามารถระบุ mapping แบบ dot-path ได้ชัดเจน

items_path: `data.items`
title_field: `title`
link_field: `url`
date_field: `published_at`
summary_field: `summary`

HTML

ต้องมี fetcher เฉพาะ

ใช้กับหน้าเว็บทั่วไปที่ต้อง parse จาก HTML ปัจจุบันระบบยังไม่ทำ generic HTML fetcher ดังนั้นต้องมี custom fetcher ใน Python ก่อน

รูปแบบที่ยังไม่รองรับ

JSON Feed GraphQL API Atom Feed Sitemap XML

หมายเหตุ

  • source ใหม่จะเริ่มเป็น `Inactive` ก่อนเสมอ
  • ควรกด `ทดสอบ` ให้ผ่านก่อนเปิดใช้งาน
  • ถ้าแก้ `slug`, `source_url`, หรือ `fetch_method` ระบบจะบังคับให้ทดสอบใหม่
